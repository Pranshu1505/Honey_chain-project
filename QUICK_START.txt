Activate Virtual Environment:
$ venv\Scripts\Activate.ps1

Deactivate Virtual Environment:
$ deactivate

Run Django Development Server:
$ python manage.py runserver

Run on Specific Port:
$ python manage.py runserver 8080

Open Django Shell:
$ python manage.py shell

Make Database Migrations:
$ python manage.py makemigrations

Apply Database Migrations:
$ python manage.py migrate

Create Superuser (Admin):
$ python manage.py createsuperuser

Run Tests:
$ python manage.py test

Collect Static Files:
$ python manage.py collectstatic

Check for Issues:
$ python manage.py check

📞 TROUBLESHOOTING
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Problem: Templates not found
Fix: Check TEMPLATES['DIRS'] in config/settings/base.py

Problem: Port 8000 already in use
Fix: $ python manage.py runserver 8080

Problem: Database empty
Fix: Create sample data in Django admin: http://localhost:8000/admin/

Problem: Contact form not sending emails
Fix: Configure EMAIL_* in config/settings/base.py

Problem: CSS/styling not showing
Fix: Hard refresh browser (Ctrl+F5) or check browser console
